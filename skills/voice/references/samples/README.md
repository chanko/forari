# Writing samples

Put 10 to 15 things you wrote that sound like you, one per file, like
`cold-email-acme.md` or `followup-after-demo.md`. Start the file name with the
type (cold, followup, client, exec, linkedin, internal) so Claude can pick
the right ones.

Paste the text as is. Swap out anything confidential (customer names, prices)
for something generic if you'd rather.
